# Deviations from the Part 1 documents

Differences between what was built and the SRS (`ReqTrace-SRS-01`), Test Plan (`ReqTrace-TP-01`) and
SAD (`ReqTrace-SAD-01`), with reasons. Updated every sprint and explained in the final demo.

| ID | Document | Planned | Actual | Reason |
|---|---|---|---|---|
| D-1 | Part 2 schedule, TP §6.2 | Backlog by 12 Oct; Sprint 1 19–23 Oct; Sprint 2 26–30 Oct | Backlog and both sprints executed 29–30 Oct | Team started late; scope kept, schedule compressed. GitHub timestamps are real, not backdated |
| D-2 | SAD §7 | Docker Compose only | Docker Compose for local use, plus Kubernetes deployment from Docker Hub images | Course requires Kubernetes and Docker Hub |
| D-3 | SRS §2.7 | FR-13, FR-14 implemented if capacity remains | Not implemented; kept in the product backlog (PB-26, PB-27) | *Could* priority; no capacity in the compressed schedule |
| D-4 | SAD §8.1 | Graphviz / Mermaid renderers in the back end | Mermaid source from the UML agent, rendered and exported to PNG in the browser | Avoids a headless browser in the back-end image |
| D-5 | SAD §5 | Background tasks for large generations | Generation runs synchronously with a progress message | Gemini Flash returns well inside the 60 s limit; simpler |
| D-6 | TP §5 | Tests against PostgreSQL | Automated tests use in-memory SQLite; Compose and Kubernetes use PostgreSQL 15 | Fast CI without a database service |
| D-7 | SEC-07, SAD §9 | TLS at nginx | TLS at nginx with a self-signed certificate generated at start-up | No public domain or CA certificate for a course demo |
| D-8 | SAD AD-7 | Stateless JWT sessions | Signed JWT plus a server-side session row | SEC-02 requires tokens to be invalidated at logout and to expire after 60 minutes of inactivity, which needs server-side state |
| D-9 | SRS App. B | Abhinav D as team lead | Ashwin Anand is Scrum Master and repo owner, reviewing and merging all PRs | Team decision at sprint planning |
| D-10 | SRS UC4, UC6 | Tests and test plan generated by the QA Engineer | QA Engineer, Analyst and Administrator may generate them | Lets the analyst complete the flow when no QA is assigned; approval stays Analyst/Admin only |
| D-11 | SAD §8.1 | "LLM provider API" | Google Gemini free tier (`gemini-3-flash-preview`, fallback `gemini-3.1-flash-lite`) | Free-tier constraint (SRS §2.5); older default model retired for new keys (bug #28) |
